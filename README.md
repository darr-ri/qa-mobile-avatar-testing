##Задание 1. Сценарии для тестирования

###Позитивные сценарии:

Загрузка валидного JPEG-файла размером до 5 МБ с чётким изображением реального лица.
Загрузка валидного PNG-файла размером до 5 МБ с чётким изображением реального лица.

###Негативные сценарии:

Загрузка файла неподдерживаемого формата (GIF, PDF).
Загрузка файла размером больше 5 МБ.
Загрузка повреждённого или пустого файла (0 КБ).
Загрузка изображения без лица (пейзаж, животное, предмет).
Загрузка изображения с несколькими лицами.
Загрузка размытого/нечёткого лица.
Загрузка изображения, сгенерированного ИИ.

###Граничные значения:

Загрузка файла ровно 5 МБ.
Загрузка файла 5.01 МБ.
Загрузка минимального по размеру файла.

###Сценарии прерывания и работы с сетью:

Потеря интернет-соединения во время загрузки.
Входящий звонок или сворачивание приложения во время загрузки.
Нажатие кнопки «Отмена» на разных этапах.

###Сценарии работы с UI/UX и устройством:

Поворот экрана (портретная/ландшафтная ориентация).
Отсутствие разрешений на доступ к галерее или камере.
Работа на разных версиях Android (например, Android 11, 13, 14) и разных диагоналях экрана.

##Задание 4. Техники тест-дизайна

###Классы эквивалентности:

Форматы: JPEG и PNG (валидные) / Все остальные форматы (невалидные).
Размер: ≤ 5 МБ (валидные) / > 5 МБ (невалидные).
Контент: Реальное фото с лицом (валидное) / Без лица, ИИ, размытое (невалидные).

###Анализ граничных значений:

Проверка размера файла: 4.99 МБ, 5.00 МБ, 5.01 МБ.
Проверка минимального размера файла (0 байт).

###Попарное тестирование:

Использовала для сокращения количества тестов при комбинации параметров: Формат (JPEG/PNG) × Размер (<5МБ, =5МБ, >5МБ) × Контент (лицо, без лица, ИИ).

###Предугадывание ошибок:

Основываясь на опыте, я добавила проверки: прерывание звонком, отключение интернета, загрузка повреждённого файла, поворот экрана.
